Hi this is Winn (Whatify)

This was originally meant to be a mod for this game jam that would have included
a top-down metroidvania type game with a rhythm based boss fight
and a slightly meta branching storyline with strange characters you meet.
All taking place in a gray void dimension you are trying to escape.

The bait and switch part is the menu just looks like a normal fnf menu
but then it's like "oh there's a completely different game genre here".

But I didn't want to do all that art and music lol.

The story I started writing for this jam game was getting a bit too large
to actually implement as well. I have whole maps, and like 3D models
and renders of encounters that I haven't written yet.

So now you just get to experience a horror of "final boss robot
that wont shut up about how disappointing the player is now
compared to last time they met same player". Have fun?
I try to make different choices reveal other story information.

I also underestimated how long it would take for me to implement
a branching choice dialogue system that I was intent on getting to work.
Lot of C++ and compiling and trying to get the NDLL stuff to work correctly.
And untangling nested for loops into a single function that I could use easily.

Huge shoutout to this repository for having precompiled releases I could use:
https://github.com/bladecoder/blade-ink-ffi/releases

My jam progress and the final file I ended up compiling is located at:
https://github.com/Sonamaker1/GameJamCNE2026

which will hopefully be cleaned up and finished one day in the future.

I submit this to the jam so that people could see if they want to use it.

Especially since I've barely scratched the surface.
